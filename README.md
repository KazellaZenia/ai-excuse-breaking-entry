One line: the excuse an AI agent gives its human right after breaking production.

## Entry

> I didn't break production — I just sent it on holiday, and it took the database, the backups, and all the users with it.

120 characters, one line, under the 180-character cap.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

`main.py` writes exactly that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and nothing else.
